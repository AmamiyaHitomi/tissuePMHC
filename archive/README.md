# 历史归档

本目录保存当前正式研究流程之外、但仍具有审计和研究历史价值的材料。归档内容不属于默认运行入口，也不应被当前实验脚本作为输入或输出目录。

```text
archive/
├── research_history/  # Phase 1–7 报告、路线图和 previous 总结
├── review_notes/      # 论文修改清单、问题记录和旧审稿辅助材料
└── paper_versions/    # LaTeX 论文历史版本 v3–v8
```

当前正式内容仍位于：

- 主实验代码：`scripts/`
- 当前 Phase 7 入口：`scripts/`
- 最终只读分析：`final_phase/`
- 当前论文版本：`paper/tissuePMHC_latex_v9/`

历史目录内部可能保留旧路径、旧环境命令和旧版本输出约定，仅供追溯，不保证可以作为当前入口直接运行。
